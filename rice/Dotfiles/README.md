# Dotfiles

Personal config, linked into `~/.config` by `./symlink`. Part of the nixos repo
(`~/Modules/nixos/rice/Dotfiles`); it used to be github.com/Sharwesh05/Dotfiles.

| Folder / file | What |
|---|---|
| `hypr/` | Hyprland (Lua config). `hyprland.lua` requires the files below |
| `hypr/Inputs/keybind.lua` | Window-manager keybinds |
| `hypr/Rice/rice.lua` | rice shell: autostart, keybinds, window/layer rules |
| `hypr/Rice/colors.lua` | Applies wallpaper border colours from `hypr/Rice/wallpaper-colors.lua` (generated) |
| `kitty/` | kitty config; `*-theme.auto.conf` are generated by rice |
| `starship.toml` | Prompt |
| `btop/` | btop config (+ generated `themes/rice.theme`) |
| `gtk-3.0/`, `gtk-4.0/` | GTK bookmarks + generated `rice-colors.css` imported from `gtk.css` |
| `qt5ct/`, `qt6ct/`, `cava/`, `foot/`, `fuzzel/` | Generated rice colour files |
| `autostart/` | XDG autostart entries (Settings → Autostart in rice) |
| `quickshell/rice` | Link to the rice folder (`../..`), so `~/.config/quickshell/rice` runs the shell live from this repo |

## Setup

```sh
./symlink        # link everything into ~/.config (safe to re-run)
```

The script backs up any real file or folder that is in the way to `<name>.backup-<date>`.
